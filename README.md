# Credit_Card_Financial_Dashboard

# 📊 Project Title / Headline

## CREDIT CARD FINANCIAL DASHBOARD

An interactive and analytical Microsoft Power BI Dashboard designed to monitor credit card transactions, customer spending behavior, revenue trends, and financial performance insights across different customer segments, card categories, and time periods.

# Short Description / Purpose

The Credit Card Financial Dashboard is a dynamic and visually interactive Power BI report created to analyze financial transaction data and customer activity related to credit card usage. The dashboard helps track revenue, transaction amount, customer income groups, expenditure patterns, and card usage behavior through powerful KPI metrics and interactive visualizations.

This dashboard is useful for financial analysts, banking professionals, credit card companies, business managers, and data analysts who want to monitor customer spending trends, improve financial decision-making, and identify profitable customer segments.

# Tech Stack

The dashboard was built using the following tools and technologies:

* 📊 Microsoft Power BI Desktop – Main platform used for building interactive dashboards and visual reports.
* ⚙️ Power Query – Used for data cleaning, preprocessing, and transformation.
* 🧠 DAX (Data Analysis Expressions) – Used for calculated measures, KPIs, and dynamic financial analysis.
* 🗂️ Data Modeling – Relationships created among customer and transaction tables for filtering and analysis.
* 🗄️ SQL – Used for importing and managing financial transaction data.
* 📁 Excel / CSV Dataset – Used as the primary source for customer and transaction records.
* 🖼️ PNG Format – Used for dashboard preview images and GitHub presentation.

# Features / Highlights

## • Business Problem

Financial institutions generate huge volumes of transaction data daily, making it difficult to manually monitor customer behavior, spending trends, revenue growth, and financial performance.

Important business questions such as:

* Which customer segment generates the highest revenue?
* Which card category is most used?
* What are the top expenditure types?
* Which quarter shows maximum revenue growth?
* Which states contribute the highest transactions?
* What customer group generates the highest interest income?

…are difficult to analyze quickly using raw spreadsheets and transaction records.

## • Goal of the Dashboard

The goal of this dashboard is to provide an interactive financial analytics solution that:

* Helps monitor overall revenue and transaction performance
* Tracks customer spending and financial behavior
* Identifies high-value customer segments
* Analyzes card category usage and expenditure types
* Supports data-driven financial decision-making
* Simplifies complex transaction data into easy-to-understand visual insight.

# Walkthrough of Key Visuals

## 🔹 KPI Cards (Top Section)

Displays important financial metrics including:

* Total Revenue
* Total Transaction Amount
* Total Interest Earned
* Total Transaction Count

These KPIs provide a quick overview of overall financial performance.

## 🔹 Revenue by Card Category (Bar Chart)

Shows revenue generated by different card categories such as:

* Blue Card
* Silver Card
* Gold Card
* Platinum Card

Helps identify the most profitable card type.

## 🔹 Revenue by Expenditure Type (Donut Chart)

Displays customer spending distribution across categories like:

* Bills
* Entertainment
* Fuel
* Grocery
* Food
* Travel

Helps understand customer expenditure behavior.

## 🔹 Quarterly Revenue Trend (Line / Column Chart)

Visualizes quarterly financial performance and highlights periods of growth or decline.

## 🔹 Customer Income Group Analysis

Shows revenue contribution from different income groups to identify high-value customer.

## 🔹 Revenue by Gender (Donut Chart)

Compares revenue contribution and transaction behavior between male and female customers.

## 🔹 State-wise Transaction Analysis (Map / Bar Chart)

Displays state-level customer transactions and revenue contribution to identify high-performing regions.

## 🔹 Interest Earned Analysis

Shows how much interest revenue is generated from different customer categories and card types.

## 🔹 Interactive Filters / Slicers

Allows users to filter data dynamically by:

* Quarter
* Gender
* Card Category
* Income Group
* State

Enabling customized financial analysis and deeper business insights.
